Tools

AegisCode exposes direct file, shell, job, git, browser, audit, snapshot, and todo tools with guardrails and JSON audit logs.

GroupCommandsNotes
fileread, write, edit, patch, delete, glob, grep, treeWorkspace-bound paths. Delete requires approval.
shellrun, start, list, read, send, killSessions prefer tmux on Unix. Windows ConPTY can be added later.
jobstart, list, tail, killMetadata and logs persist under .aegiscode/runtime and .aegiscode/logs.
gitstatus, diff, add, commit, push, branch, logCommit and push require approval.
browsertext, screenshot, pdfScreenshot and PDF use optional Playwright.
governanceaudit, snapshot, todoAudit is JSONL. Snapshot restore requires approval.
