AegisCode

AegisCode is an opencode-style coding-agent CLI with governed tools, durable subagents, approvals, snapshots, audit logs, provider adapters, and portable releases.

Install

pipx install aegiscode
uv tool install aegiscode
npm i -g aegiscode

Project setup

aegiscode init
aegiscode doctor

Initialization creates AGENTS.md, .aegiscode/config.toml, and .aegiscode/subagents.json.

Run

aegiscode run "review the current diff"
aegiscode serve

The local WebUI is available through aegiscode serve at http://127.0.0.1:8080.

Subagents

aegiscode subagent list
aegiscode subagent queue --agent planner --task "Plan the release"
aegiscode subagent run-next
aegiscode subagent run-all

Approvals

aegiscode approval list
aegiscode approval approve <approval-id>
aegiscode approval reject <approval-id>

Providers

Supported providers: mock, openai-compatible, and github-models.
