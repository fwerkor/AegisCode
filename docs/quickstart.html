Quickstart

Initialize a project, run an agent task, inspect tools, and use the direct CLI without leaving the terminal.

  • Initialize
  • Run
  • Direct tools
  • Subagents

Initialize

aegiscode init

This writes AGENTS.md, .aegiscode/config.toml, and .aegiscode/subagents.json.

Run

aegiscode "fix tests"
aegiscode run "fix tests"

The first form is a shortcut for the second form.

Direct tools

aegiscode file read README.md
aegiscode shell run python -m pytest -q
aegiscode git status
aegiscode doctor

Subagents

aegiscode subagent pipeline default --task "prepare release"
aegiscode subagent run-all --max-count 5
