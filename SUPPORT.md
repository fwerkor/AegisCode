# Support

AegisCode is developed as an open-source project. Support is best-effort and centered on reproducible technical information.

## Getting help

Use GitHub issues for:

- Reproducible bugs.
- Feature requests.
- Documentation gaps.
- Packaging, installer, Docker, CI, and release problems.

Use security reporting for vulnerabilities. Do not post secrets, tokens, private logs, or sensitive workspace contents in public issues.

## Before opening an issue

Check the latest release and current `main` branch. Include:

- AegisCode version or commit SHA.
- Installation method.
- Operating system and Python version.
- Command that failed.
- Minimal reproduction steps.
- Relevant logs with secrets removed.

## Not covered

The project does not provide guarantees for production deployments, third-party provider outages, unsupported forks, local environment corruption, or unsafe modifications that bypass AegisCode guardrails.
