## Maintainer responsibilities

- Review and merge pull requests.
- Triage issues and security reports.
- Keep governance-sensitive code paths protected.
- Publish releases and verify release artifacts.
- Maintain documentation and contributor expectations.

## Becoming a maintainer

A contributor may be considered for maintainer access after sustained, high-quality contributions across code, tests, documentation, and review. Maintainer access should be granted gradually and only where it improves project health.
