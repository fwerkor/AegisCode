# Code of Conduct

## Our standards

AegisCode should remain a practical, technically focused, and safe project space. Participants are expected to:

- Be respectful and precise in issues, reviews, and discussions.
- Critique code, design, tests, and documentation rather than people.
- Assume good intent, but correct unsafe or misleading behavior clearly.
- Keep discussions relevant to the project.
- Avoid harassment, threats, personal attacks, discriminatory language, or repeated disruptive behavior.

## Scope

This code applies to all project spaces, including GitHub issues, pull requests, discussions, documentation, release channels, and any other official AegisCode community venue.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests; restrict repository access; or block participants when behavior harms the project or its contributors.

Enforcement should be proportional, documented when practical, and focused on preserving a useful development environment.

## Reporting

Report conduct concerns privately to the maintainers. If the concern is also security-sensitive, follow `SECURITY.md` instead of opening a public issue.
